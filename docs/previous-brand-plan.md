## 1. 시장 조사 요약 — 한식뷔페 & 한식 프랜차이즈

### 1-1. 한식뷔페 흥망 타임라인

| 시기 | 국면 | 핵심 사실 |
|---|---|---|
| 2013~2016 | 확장기 | 계절밥상 2013.7 1호점 → 최대 54개점. 자연별곡 40여 개, 풀잎채 47개(2016), 올반 14개 |
| 2017~2019 | 정체기 | 중소기업 적합업종 규제 + 1인 가구·배달 확산. 풀잎채 47→21개, 계절밥상 54→16개. 2018년 자연별곡 1호 미금점 폐점 |
| 2020~2022 | 철수기 | 풀잎채 회생절차(2020), 올반 브랜드 철수, 계절밥상 코엑스몰점 폐점(2022.4)으로 브랜드 소멸 |
| 2023~2025 | 가성비 회귀 | 3년 연속 3%대 외식물가 상승. 8,000원대 로컬 한식뷔페 성업. 애슐리퀸즈 매출 1,160억(2021)→5,000억(2025) |
| 2026 | 재점화 | 자연별곡 리뉴얼 — 메뉴 100→60종, 평일 15,900원, 이용 90분. 야탑점 첫 주 5,000명, 회전율 평균 7.7회(최대 9.8회) |

### 1-2. 한식 프랜차이즈 지표 (공정위 2025년도 가맹사업 현황, 2026.4 발표)

- 전체 가맹본부 9,960개 / 브랜드 13,725개 / 가맹점 379,739개 (전년비 +13.2% / +10.9% / +4.0%)
- 외식업 브랜드 10,886개, 가맹점 183,714개, **가맹점 평균 매출 3.51억 원(+6.1%)**
- **한식 가맹점 43,882개(외식 세부업종 1위, 23.9%)**, 증가율도 +6.1%로 1위
- 한식 가맹점 평균 매출 증가율 **+8.3%** (커피와 공동 최상위)
- 전체 브랜드의 74.4%가 가맹점 10개 미만 소규모 → 표준화된 중대형 모델의 공백

### 1-3. 전략적 결론 4가지

1. **실패 원인은 '한식'이 아니라 구조** — 100종 메뉴 / 2만원 후반 / 120분 조합은 원가·인건비를 감당할 수 없었다.
2. **해법은 '집중 + 회전'** — 60종 / 90분 / 1만원대로 바꾼 리뉴얼 매장이 회전율 7.7회, 매출 +48%로 증명.
3. **가격 공백 구간 존재** — 8,000원 로컬 뷔페(위생·일관성 리스크)와 2만원 프리미엄 뷔페(가격 저항) 사이의 **1.2~1.7만원 준프리미엄 가성비** 구간이 비어 있다.
4. **표준화 모델 부재** — 한식 가맹점 43,882개 중 뷔페형 표준 모델은 사실상 없음. 100평 표준 설계 + 물류 표준화로 선점 가능.

## 2. 브랜드 컨셉 · 로고 · 슬로건

### 2-1. 컨셉

**밥상궁(飯床宮) = 밥상 + 궁(宮).** 임금의 수라상을 차려내던 반상 문화를, 매일 반복되는 한 끼의 언어로 옮긴다.
화려함이 아니라 **정갈함과 온기**가 중심. 포지셔닝은 *준프리미엄 가성비 한식 반상 뷔페*.

3대 필러:

| 필러 | 영문 | 내용 |
|---|---|---|
| 반상의 격 | THE BANSANG | 12첩 반상의 구성 원리를 배식 동선에 그대로 이식. 밥·국·주찬·반상찬·후식 순서 배치, 일 60종 |
| 솥밥과 화로 | LIVE FIRE & POT | 당일 도정 쌀 솥밥 + 즉석 화로구이·전 라이브 코너. '갓 지은 것'의 온기가 핵심 체험 |
| 90분의 완결 | 90 MIN COURSE | 체류 90분 설계로 회전율 확보 → 그 이익을 식자재 등급과 가격에 환원 |

### 2-2. 로고 (인장형 엠블럼 + 붓글씨 워드마크)

- **기와지붕 솥뚜껑과 김** — 솥뚜껑을 궁궐 기와지붕으로 치환. 피어오르는 두 줄기 김은 '갓 지은 것'의 온기
- **가마솥** — 양옆 손잡이까지 그려낸 통가마솥. 한 그릇이 아니라 상을 통째로 차려낸다는 뷔페의 넉넉함
- **아궁이의 불** — 솥 아래 불꽃. 매장에서 직접 짓는 솥밥과 화로 라이브 코너, 즉 '직화' 조리 방식
- **인장 프레임(印章)** — 금선을 두른 사각 인장 테두리. 맛과 위생에 대한 본사 보증 (심볼만 떼어 간판·포장·유니폼에 단독 사용)
- **붓글씨 워드마크** — 손글씨 휘림의 '밥상궁'. 수라상의 격식과 집밥의 손맛을 동시에 전달

### 2-3. 슬로건 체계

- 메인: **“매일 차리는 궁의 밥상”** / 영문 `THE ROYAL TABLE, EVERY DAY`
- 고객용 서브: “한 끼가 대접이 되는 곳”
- 시즌 캠페인: “오늘 점심, 임금님처럼”
- 가맹 모집용: “검증된 한 끼, 검증된 회전율”

### 3-3. 정보 구조 (조사 결과 → 화면 설계)

조사에서 도출한 "실패는 구조 때문, 해법은 집중+회전, 공백은 1만원대" 논리를 그대로 스크롤 순서로 옮겼다.

1. **히어로** — 슬로건 + 가격 3종 + 90분을 즉시 노출 (가성비 의사결정 정보 우선)
2. **시장 인사이트** — 공정위 통계 4지표 + 13년 타임라인 + 결론 4개 (가맹 희망자 설득 근거)
3. **브랜드** — 컨셉 3필러, 로고 해설, 슬로건 체계, 컬러 팔레트
4. **메뉴** — 6개 존 60종 구조 + 가격표 (가짓수 경쟁이 아닌 '구성' 강조)
5. **100평 설계** — 3D 아이소 도면 / 2D 평면도 / 3D 조감도 3탭 + 존 클릭 인터랙션 + 면적 배분표
6. **인테리어 갤러리** → 7. **가맹 안내**(비용·수익 시뮬레이션·프로세스·상담폼) → 8. **매장 안내**

## 4. 100평 표준매장 설계 (필수 포함 항목)

**전용 330.0㎡ (99.8평) · 22.0m × 15.0m · 96석**

### 4-1. 면적 배분

| 존 | 구성 | 면적 | 비중 |
|---|---|---|---|
| 주방 · 후방지원 | 저장·냉장냉동 / 메인 조리 / 배식 팬트리 / 세척·퇴식 / 직원실 | 88.0㎡ | 26.7% |
| 뷔페 배식존 | 후식·음차 / 화로 라이브 / 즉석 전·면 / 핫푸드 A / 반상찬 B / 솥밥·국탕 | 95.7㎡ | 29.0% |
| 홀 객석 | 4인석 16 · 창가 2인석 8 · 벤치석 | 92.7㎡ | 28.1% |
| 프라이빗 룸 '궁실' | 8인실 × 2 | 27.4㎡ | 8.3% |
| 입구 · 대기 · 카운터 | 풍제실 · 대기벤치 · POS · 키오스크 2 | 14.0㎡ | 4.2% |
| 화장실 · 파우더 | 남 · 여 | 12.2㎡ | 3.7% |

### 4-2. 주요 제원

- 좌석 96석 (홀 80 + 룸 16) / 배식 라인 22.4m, 6개 존
- 주 통로 1.5m, 배식대 앞 1.4m, 아일랜드 사이 1.2m
- 예상 일 방문 280~420명 (회전 3.0~4.4회), 필요 인력 12명(홀 5 · 주방 7)

### 4-3. 동선 원칙

- **고객** 입구 → 대기·POS → 착석 → 배식(시계방향 1방향) → 퇴식대 → 출구
- **리필** 주방 팬트리 → 후방 서비스 통로(1.4m) → 아일랜드 후면 리필도어 (고객 동선과 무교차)
- **위생** 식자재 반입구와 퇴식·폐기 동선을 좌우 분리, 세척실은 퇴식대 바로 뒤

### 4-4. 확장 옵션

- 80평형: 프라이빗 룸 1실 + 화로 라이브 축소
- 120평형: 단체석 2조 + 대기 라운지 추가
